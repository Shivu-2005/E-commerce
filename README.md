
# E-commerce Backend (Integrated)

Modules:
- Product Module
- Category Module
- Order Module

## Install
npm install

## Run
node index.js

Server:
http://localhost:5000

## APIs

Products
GET /products
POST /products

Categories
GET /categories
POST /categories

Orders
GET /orders
POST /orders

Example Order Body:
{
 "productId":1,
 "quantity":2
}
